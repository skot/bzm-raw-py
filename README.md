Python bringup and test scripts for the [bitaxeBIRDS](https://github.com/bitaxeorg/bitaxebirds) with [bitaxe-raw-pico](https://github.com/bitaxeorg/bitaxe-raw/tree/pico)

- vr-bringup.py -> configure and enable the TPS546D24S voltage regulator.
- asic_comm.py -> set ASIC_ID on each of the 4 BZM2 chips.
- fan_tester.py -> set and monitor fan speed.
